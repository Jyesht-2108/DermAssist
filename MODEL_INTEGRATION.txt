✓ TECHNICAL DETAILS
--------------------
Preprocessing Pipeline:
- Input: JPEG image bytes from camera
- Decode: Convert to RGB image
- Resize: 224x224 with linear interpolation
- Normalize: (pixel - 127.5) / 127.5 → [-1, 1]
- Output: 224x224x3 float tensor

Model Architecture:
- Base: MobileNetV2
- Quantization: INT8 (4x smaller, faster)
- Input Shape: [1, 224, 224, 3]
- Output Shape: [1, 1001] (ImageNet classes)
- Optimized for mobile inference

Performance:
- Model Size: 3.4 MB
- Inference Time: ~100-500ms (device dependent)
- Memory Usage: <50 MB
- 100% on-device processing
- No internet required
- Complete privacy
