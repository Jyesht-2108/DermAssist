🚀 GET STARTED IN 3 STEPS
═══════════════════════════════════════════════════════════════

STEP 1: Install Dependencies
────────────────────────────────────────────────────────────────
$ flutter pub get

Expected output: "Got dependencies!"


STEP 2: Verify Model File
────────────────────────────────────────────────────────────────
$ ls -lh assets/models/skin_model.tflite

Expected output: "3.4M skin_model.tflite"

If missing, run:
$ python3 scripts/download_model.py


STEP 3: Run the App
────────────────────────────────────────────────────────────────
$ flutter run

Expected: App launches on connected device


═══════════════════════════════════════════════════════════════

📱 USING THE APP
═══════════════════════════════════════════════════════════════

1. LAUNCH
   - Wait for splash screen
   - Model loads automatically
   - See "AI Model Ready" status

2. SCAN
   - Tap "Scan Skin" button
   - Grant camera permission
   - Position skin area in frame

3. CAPTURE
   - Tap capture button
   - Wait for "Processing image..."
   - View results automatically

4. RESULTS
   - See condition name
   - Check confidence %
   - Note risk level
   - Tap "Scan Again" to repeat

═══════════════════════════════════════════════════════════════

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "Failed to load ML model"
Solution: Model file is missing or in mock mode
          This is normal for testing without real model

Problem: "Camera permission denied"
Solution: Go to device settings and grant camera permission

Problem: "Failed to capture image"
Solution: Ensure camera is working and try again

Problem: "Analysis failed"
Solution: Ensure good lighting and clear image
