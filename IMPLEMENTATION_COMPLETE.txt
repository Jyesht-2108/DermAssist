🎬 HOW TO RUN
═══════════════════════════════════════════════════════════════

1. Install dependencies:
   $ flutter pub get

2. Verify model exists:
   $ ls -lh assets/models/skin_model.tflite

3. Run the app:
   $ flutter run

4. Test on device:
   - Grant camera permission
   - Tap "Scan Skin"
   - Capture image
   - View results
