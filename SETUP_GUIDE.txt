REQUIRED BEFORE RUNNING
------------------------
1. Add your trained TFLite model:
   - Place file at: assets/models/skin_model.tflite
   - Model must accept 224x224x3 RGB input
   - Model must output probability vector

2. Connect a device or start emulator:
   flutter devices

3. Run the app:
   flutter run

TESTING THE PIPELINE
--------------------
Once model is added:
1. App launches with splash screen
2. Model loads automatically
3. Home screen shows "AI Model Ready" status
4. Tap "Scan Skin" to open camera
5. Capture image to run inference
6. Results displayed with confidence score

TROUBLESHOOTING
---------------
If model fails to load:
- Verify skin_model.tflite exists in assets/models/
- Check pubspec.yaml includes assets/models/ in assets section
- Run: flutter clean && flutter pub get

If camera fails:
- Check permissions granted on device
- Verify AndroidManifest.xml has camera permissions
- Verify Info.plist has NSCameraUsageDescription
